# Ableitung einer Exponentialfunktion

Teil von [[Mathe]].

## Regel

Für eine Exponentialfunktion $f$ mit $f(x) = b^x$ gilt

$$f'(x) = c \cdot b^x \qquad \text{mit } c = f'(0)$$

## Folgerungen

- Die Ableitung $f'$ einer Exponentialfunktion ist **wieder eine Exponentialfunktion**
- Der Graph von $f'$ entsteht aus dem Graph von $f$ durch **Streckung parallel** [?] zur $y$-Achse

## Herleitung über den Differenzenquotienten

$$\frac{f(x_0 + h) - f(x_0)}{h} \;\longrightarrow\; \text{ausgeklammerte Darstellung} \;\xrightarrow{\;\lim_{h \to 0}\;}\; c$$
